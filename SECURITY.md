# Security policy

## Supported versions

This repository is a public source preview and has no supported stable release yet. Security fixes for the current MVP are reviewed on main.

## Report a vulnerability

Use GitHub's **Report a vulnerability** option under the repository's Security tab when available. If it is unavailable, open a minimal issue requesting a private reporting channel. Do not post exploit details, credentials, personal audio, or transcripts publicly.

Include the affected commit, reproducible steps, impact, and a safe proof of concept. There is no guaranteed response time during the preview period.

The default local path uses no cloud credentials. The optional legacy Azure adapter is outside the default desktop package. If an Azure key from a separate build may have been exposed, rotate it in Azure and remove it from local or published copies.
