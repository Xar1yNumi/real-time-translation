# 无 Azure 凭据的本机试用检查点

日期：2026-10-31。此检查点供项目负责人体验现有 MVP 的本机部分，**不是**完整翻译验收或正式发布许可。没有 Azure Speech Endpoint 和 Key 时，当前程序不会生成真实译文，“开始翻译”保持禁用。

## 可交付的本机试用包

从当前源码生成的 `artifacts/RealTimeTranslation-win-x64.zip` 为自包含 Windows x64 文件夹包，仅供项目负责人本机试用，未发布到 GitHub Releases，也未创建 `v0.1.0` 标签。校验值由打包流程写入同目录的 `.sha256` 文件，打包后单独核对。它包含 `RealTimeTranslation.Desktop.exe`、Azure Speech 原生 DLL、项目许可证、中英文 README 及 README 所链接的仓库文档。本机解压后启动设置窗口成功，关闭窗口后进程退出；尚未在另一台干净的 Windows 电脑上验证。第三方组件的再分发许可与条款尚待逐项核对，正式对外提供二进制包前必须完成此项。

## 已现场检查

- 设置窗口显示 Azure 音频上传与可能产生费用的说明；没有凭据时“测试连接”和“开始翻译”均禁用。
- 系统声音与麦克风可切换，当前设备名称随选项更新；简体中文、英语、俄语三个目标语言可选择。
- `Category=WindowsAudioManual` 的默认系统回环与麦克风各 5 秒真实采集测试：2 项通过、0 失败；系统回环测试播放约 4 秒合成测试音，不保存捕获音频。
- 锁定依赖还原、格式检查、Release 编译均通过；Release 编译为 0 警告、0 错误。常规全量测试为 107 项：103 项通过、4 项按现场条件跳过，其中一项是缺少 Azure 凭据的真实云端测试。
- 仓库说明文件及新试用 ZIP 内中英文 README 的本地相对链接检查均无缺失；ZIP 中未发现名为本机设置、日志、语音 WAV、证书或凭据的文件。此检查不能代替正式发布前的完整敏感信息审计。
- 2026-10-30 的系统回环 30 分钟**仅采集**稳定性测试已记录在[技术可行性报告](feasibility/azure-audio-report.md)，本次没有重复运行。它不能替代 30 分钟 Azure 端到端翻译。

## 试用方法与边界

把 ZIP 解压到一个普通文件夹，运行其中的 `RealTimeTranslation.Desktop.exe`。可以检查设置窗口、默认设备名称、音源与目标语言选择、窗口退出及随包文档。没有 Azure 凭据时，正常产品流程无法打开字幕条、采集会话或展示真实译文。悬浮字幕的暂停、恢复、拖动与置顶行为目前只有自动化测试和设计检查点，尚未在真实翻译会话中由用户现场验收。

若项目负责人决定最终不依赖 Azure 而仍需要真实翻译，必须另外选择语音识别和翻译实现，并对其准确率、延迟、成本及稳定性重新设计和验收。当前试用结果不能证明替代实现已存在或可满足目标。
