# 免 Azure 联网短时翻译试用版设计

- 日期：2026-10-31
- 状态：方案已由项目负责人确认；本文件替代旧设计中“Azure 凭据是启动前提”的试用要求
- 目标平台：当前 Windows x64 电脑；C#、WPF、.NET 10

## 目标与边界

用户不注册服务、不填写 API Key，联网后可选择系统声音或麦克风之一，选择简体中文、英语或俄语作为目标语言，点击“开始翻译”并看到真实的原文与译文悬浮字幕。语音来源可在三种语言之间逐句变化；同一句话内部混说不列入本次试用要求。Azure 是否重新加入产品，等项目负责人体验后决定。

这是**短时真实翻译试用版**，不是正式 `v0.1.0` 发布验收。匿名翻译接口每天 5,000 字符，不能据此宣称 30 分钟连续翻译稳定或无限制免费。当前 Azure 端到端、断网恢复和 30 分钟云端运行检查仍未完成。

## 方案取舍

1. **采用：本机识别语音 + 匿名在线文本翻译。** 本机 Whisper 模型将音频转为文字；只有点击开始后确认的原文通过 HTTPS 发给 MyMemory，返回译文。运行时需要互联网。用户无需 Azure、其他账号或密钥。该方案可快速交付真实译文，但受匿名额度、第三方隐私条款和服务可用性约束。
2. 自建在线翻译服务：终端用户也可免注册，且能控制额度和隐私策略；项目负责人必须承担服务器、模型运行、滥用防护和维护成本。本轮不实施。
3. 全本地语音识别与翻译：首次下载后可断网使用；不符合项目负责人“运行时必须联网”的本轮要求。本轮不实施。

MyMemory 的[接口文档](https://mymemory.translated.net/doc/spec.php)规定 `get` 请求的 `q` 最大 500 字节，`langpair` 使用源/目标语言代码；[用量说明](https://mymemory.translated.net/doc/usagelimits.php)规定匿名每天 5,000 字符。[服务条款](https://mymemory.translated.net/terms-and-conditions)涉及提交内容及访问数据的处理，因此界面必须明确告知用户，不应把该模式描述为适合私密通话。2026-10-31 在当前电脑上，六个方向的非敏感样句均得到 HTTP 200 和非空译文；这只是可达性检查，不是长期可用性保证。

## 数据流与组件

```text
Windows 系统回环 / 麦克风（二选一）
  -> 现有 16 kHz 单声道 PCM 转换及有界音频队列
  -> 本机短句分段与单任务识别队列
  -> Whisper.net + 多语言 Whisper small Q5_1 模型
  -> 原文、检测语言、语句 ID
  -> MyMemory HTTPS get（源语言与目标语言不同的句子）
  -> FinalUtteranceUpdate
  -> 现有字幕状态与置顶悬浮窗口
```

- 音频保持在本机，不上传给 MyMemory，也不持久化。确认的原文会发送给 MyMemory；返回译文只在内存和当前字幕中存在。诊断日志不得包含音频、原文、译文或完整请求 URL。
- 模型固定为 `ggml-small-q5_1.bin` 多语言版，190,085,487 字节；首次使用时从 `ggerganov/whisper.cpp` 的提交 `c521a4b02f422512d734391fdf08bb08c0862f68` 下载至 `%LOCALAPPDATA%/RealTimeTranslation/models`，下载到临时文件、验证 SHA-256 `ae85e4a935d7a567bd102fe55afc16bb595bdb618e11b2fc7591bc08120411bb` 后原子替换。下载失败、校验失败、磁盘不足时不允许启动翻译，并显示明确错误。模型文件不提交 Git，也不放入初始源码仓库。
- 先使用 Whisper.net 的 Windows CPU 运行时以避免 GPU 驱动和 CUDA 安装前提；当前电脑有 Ryzen 7 5800H、16 GB 内存和 RTX 3060 6 GB，GPU 加速可在后续性能实测后另行决定。语音模型和运行库的再分发许可在公开二进制发布前核对。
- 分段器以短暂静音确定语句结束；音频缓存和待识别语句数量均有上限。持续无静音时强制切段；处理速度落后时有明确丢帧/积压提示，不能无限占用内存。
- 自动识别只接受 `zh`、`en`、`ru`。检测为其他语言或未能检测语言时显示识别失败，不猜测译文。源语言和目标语言相同时原文直接作为字幕，不计作一次在线翻译。
- MyMemory 以 UTF-8 编码请求单句，限制 500 字节；对 HTTP、JSON、空译文、配额和超时分别给出错误。网络暂时故障可按现有有界重试策略恢复，额度耗尽不重复请求。每个语句 ID 仅显示一次最终译文，旧会话结果不得污染新会话。
- 旧 Azure 实现保留在代码中供未来决定，但默认启动路径、设置窗口和短时试用不要求 Endpoint 或 Key，也不得调用 Azure 服务。公开二进制包仍受单独的第三方许可审查门槛约束。

## 交互

首次启动显示“下载语音模型”与下载进度，下载完成且用户确认“识别后的文字将发送给 MyMemory”后，才允许点击“开始翻译”。设置页保留一个音源和一个目标语言；Azure 凭据输入在这版试用流程中隐藏。运行时显示“本机识别／联网翻译”状态、原文和译文；断网、接口额度、模型或音频设备错误要可见且可恢复。关闭或返回设置后停止采集、请求和识别任务。

## 验收证据

1. 不设置任何 Azure 凭据，首次模型下载完成后，程序能启动一段真实翻译会话；断网时明确提示在线翻译不可用。
2. 用获得授权的中、英、俄短音频分别验证自动识别和六个目标方向，记录原文、译文、源语言、请求状态及从语句结束到译文出现的延迟。样句与真实音频分开验收，不用模拟返回冒充端到端证据。
3. 系统声音和麦克风分别现场测试。检查同一句不重复、暂停/恢复/退出后无旧字幕回流；配额或网络错误不使界面无响应。
4. 每个实现任务先写失败测试，再实现、编译、运行测试并独立提交。发布桌面可直接运行的试用包前，从解压目录启动并运行真实音频测试；未达到上述真实译文条件时不得称为可验收试用版。
5. 记录实测延迟、CPU/内存占用、服务额度和不足；不把短时成功写成 30 分钟稳定性结论。公开发布、Azure 取舍和长时运行属于后续决定。
