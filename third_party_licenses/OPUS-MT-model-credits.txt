Both release models are converted directly from the pinned upstream revisions
with CTranslate2 4.8.4 ct2-transformers-converter, quantization float16.
The source files, SHA-256 checksums and converted model checksums are recorded
in tools/LocalTranslation.Probe/upstream-model-manifest.json in the source
repository. The upstream model authors are Helsinki-NLP / OPUS-MT. The model
weights were not retrained; float16 conversion changes their representation.

An earlier private trial used third-party converted archives whose English-to-
Chinese license label conflicted with the upstream card. The public package
uses this independent conversion and the upstream license labels above.
See ../../third_party_licenses/SentencePiece-Apache-2.0.txt for the full Apache-2.0
text included with this package.
